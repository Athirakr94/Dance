# Athira Krishnan — Classical Dance Portfolio

A responsive, single-page starter website for a classical dancer practising Bharatanatyam, Mohiniyattam and Kuchipudi, with a dedicated Shivashakti Arts section.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a public repository named `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload `index.html` to the repository root and commit.
4. Open **Settings → Pages** and select deployment from the `main` branch / root if prompted.
5. Visit `https://YOUR-USERNAME.github.io/`.

## Personalise before publishing
- Replace the sample text in the About section with your real biography and training details.
- Replace the photo and gallery placeholders with your own images.
- Update the sample email and Instagram link in the Contact section. The YouTube link is set to https://www.youtube.com/@DanceVibeWithAthira.
- Add your performance history, awards, guru(s), and Shivashakti Arts workshop details as appropriate.

The site currently uses only HTML and CSS, so there is no build step or dependency installation.
